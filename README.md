# Assam Finance Hub

A professional Bike Loan Management Website built using HTML, CSS, JavaScript and Firebase.

---

## Features

- Firebase Authentication
- Firebase Firestore Database
- Admin Dashboard
- Bike Loan Application Form
- Search Applications
- Approve Applications
- Reject Applications
- Delete Applications
- Responsive Design
- Secure Admin Login
- Auto Refresh Dashboard

---

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Authentication
- Firebase Firestore
- GitHub Pages
